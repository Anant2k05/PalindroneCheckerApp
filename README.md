# # PalindromeCheckerApp

## Objective
To develop a Palindrome Checker Management System using Java.

## Project Flow
UC1 → Application Entry & Welcome Message  
UC2 → Hardcoded Palindrome Check  
UC3 → User Input Palindrome Check  
UC4 → Menu Driven System  
UC5 → Exit Module  

## Use Case 1 – Application Entry & Welcome Message
- Program starts from main() method
- Displays application name
- Displays application version
- Displays system initialization message
